# 打铁花序幕画布

画布：<http://127.0.0.1:16789/canvas/#/?canvas=cv_7306ce4b>

## 使用顺序

1. A 区复用人物、道具、场景资产，或单独重新生成。
2. K 区生成或修订八张关键帧；K03 预置最后确认的一手一棒握持修正版。
3. 先检查关键帧并完成修稿。
4. 双击对应 V 节点，检查自动绑定的上游关键帧和动作提示词，勾选确认再执行。参考图或提示词变化后需要重新确认。
5. 节点使用内网 ComfyUI `10.88.0.3:8179`，实际 API 图已写入各节点。图片由本地后端上传后替换到 ComfyUI 图中。
6. 主体七镜裁为 5/4/6/6/4/5/8 秒，再接七秒片名动画，混入音轨，输出四十五秒成片。画布没有剪辑渲染引擎，这一步使用 FFmpeg 或剪辑软件。

原稿保留原文；第3镜原文的举棒动作已由后续确认的低位握持方案替代，应以 K03/V03 和人工确认说明为准。

## 节点能力

- Qwen Image 2.1 资产和关键帧生成。
- MiniMax H3 Timeline 逐镜生成；高级节点提供七镜批量素材工作流。
- 视频等待窗口为三十分钟；保存任务编号，可查询上次任务而不重新提交。
- 已导入的历史素材和成片用于对照，新生成素材不会自动重剪成片。
- 创建画布本身不会请求生成接口，也不改模型共享存储或内网转发。
- 执行前检查后端变量接口版本；旧后端会提示重启，不提交未替换的工作流。

## 重建 / 更新

在项目根目录执行（读取用户指定的已有生产目录）：

```powershell
python scripts/iron_flower_canvas/create.py --source "D:\sk_show\out\2026-10-22_000028_iron_flower_prologue"
```

状态、创建前后快照位于 `.run/iron-canvas/`。脚本根据该状态更新已创建节点；重新运行会重置这些节点的配置和人工确认状态，因此开始新修稿后不要直接重跑。

本轮编译的后端程序为 `backend/.run/flowcanva-iron.exe`。需要在 backend 工作目录启动，继续使用原有数据库、上传目录和环境配置。更新代码后仍须重新编译并重启后端。
